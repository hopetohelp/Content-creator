## חלק 1 — בדיקות שנסגרו

### ✅ 1.1 נסגר 13.8.2026 — הקרדיט לא יכול לכסות את Gemini API

נבדקו שלושת חשבונות Google. **התוצאה:**

- **המפתח שבסביבה** שייך לפרויקט **"הפרויקט הראשון שלי"** — Tier 1,
  **יתרת תשלום מראש אמיתית**. משם ירדו ~$0.13 של בדיקות המחקר.
- **קרדיט ה-₪921** יושב בפרויקט **"משפחה קרובה"**, ש**אין בו מפתח כלל**.
- ואפילו אם ייווצר שם מפתח — הפרויקט ההוא ב**"ניסיון חינם"**, ו-Google
  מגדיר ניסיון כשכבה חינמית ⇒ **Lyria והתמונות חסומים שם ממילא**.
- ו-Google מחריג **במפורש** `Gemini API in AI Studio costs` מקרדיט הפתיחה.

> 🔑 **המסקנה: אין נתיב שבו הקרדיט מממן את Lyria או את התמונות.**
> מי שרוצה אותם משלם מיתרת התשלום מראש — **~₪7 לקליפ שלם.**

**⇒ אין יותר מה לבדוק בנושא הזה. נשארה רק החלטה — סעיף 0 למטה.**

### ☐ 1.2 מעקב יתרה — רק אם נבחר מסלול B *(דקה, פעם בשבוע)*

ההוצאה יורדת מיתרת תשלום מראש אמיתית. שווה לוודא שהיא לא נגמרת באמצע הפקה.

**איפה:** aistudio.google.com → בשורה של **"הפרויקט הראשון שלי"** →
**"חשבון החיוב שלי"**.

**מה מחפשים:** יתרה שנותרה. פחות מ-₪10 ⇒ להודיע לסשן לפני שמתחילים הפקה.

### ☐ 2.1 אסימון Cloudflare — לתמונות חינם *(היה חובה למסלול A)*

**למה:** ~500 תמונות ביום, בחינם, ובאיכות טובה מהנתיב הקיים.

**איפה:**

3. לבחור **Use REST API**
4. ללחוץ **Create a Workers AI API Token**
5. ללחוץ **Create API Token**, ואז **Copy API Token**
6. באותו מסך — להעתיק גם את **Account ID**

**מה להגדיר בסביבה:**

|---|---|

| `CF_ACCOUNT_ID` | ה-Account ID משלב 6 |

### ☐ 2.2 Google Flow Music — שיר אמיתי בחינם *(למסלול A+)*

**למה:** אותו מנוע Lyria 3 Pro שנותן את השיר האמיתי, אבל בחינם — במקום
ביט מסונתז וראפ מדובר. **בלי כרטיס אשראי.**

**איפה:**
1. **labs.google/fx** → לבחור **Flow Music**
2. להתחבר עם חשבון Google
3. להדביק את מילות השיר ואת תיאור הסגנון שהסוכן יכין
4. **Download** → לשמור את הקובץ

**מה לעשות עם הקובץ:** להעלות לריפו כ-`assets/audio/song.mp3` (או לשלוח לסשן).

**המחיר:** ידני, ובלי חותמות הזמן האוטומטיות — הסוכן ישלים אותן ב-`stable-ts`.
