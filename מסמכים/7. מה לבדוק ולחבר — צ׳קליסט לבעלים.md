### ☐ 1.1ב **הבדיקה החוסמת עכשיו — לאיזה חשבון שייך המפתח?** *(3 דקות)*

**איפה:**
1. **aistudio.google.com** — 🔑 **להתחבר עם החשבון שבו יש את הקרדיט**
2. בתפריט — **API keys** (או **Get API key**)
3. להסתכל בעמודה שמציגה את שם **הפרויקט** ליד כל מפתח

**מה מחפשים:** האם המפתח שמוגדר בסביבה מופיע ברשימה הזאת.

| מה רואים | המשמעות | מה עושים |
|---|---|---|
| המפתח **מופיע** ברשימה | הוא באותו חשבון | ✅ ממשיכים ל-1.2 |
| המפתח **לא מופיע** | הוא בחשבון אחר | ⬇️ ראה "התיקון" למטה |
| לא בטוח איזה מפתח זה | — | ⬇️ הפתרון הפשוט למטה עובד בכל מקרה |

#### 🔧 התיקון — פשוט יותר מלחפש

**במקום לזהות את המפתח הישן — פשוט להוציא חדש בחשבון הנכון:**

1. ב-**aistudio.google.com**, מחוברים לחשבון **שיש בו את הקרדיט**
2. **Get API key** → **Create API key**
3. לבחור פרויקט **שמקושר לחשבון החיוב עם הקרדיט**
   *(אם מוצע "Create API key in new project" — זה בסדר, ובלבד שהחשבון נכון)*
4. להעתיק, ולהחליף את `GEMINI_API_KEY` ב-claude.ai/code → **הגדרות הסביבה**

**איך יודעים שזה הצליח:** ב-console.cloud.google.com → **חיוב**, לוודא
שהפרויקט החדש מופיע תחת אותו חשבון חיוב שבו ראית את ה-₪921.

⚠️ **אם המפתח החדש יהיה בפרויקט בלי חשבון חיוב** — Lyria והתמונות ייחסמו
בשגיאה. זה לא נזק, אבל זה נועל למסלול A. הפרויקט חייב להיות מקושר
לחשבון החיוב **שיש בו את הקרדיט**.

### ☐ 1.1 (המקור) יש קרדיט חינמי פעיל ב-Google Cloud?

**למה זה חשוב:** זו השאלה היחידה שקובעת אם מותר לך להשתמש ב-Lyria (השיר)
ובתמונות של Gemini. אין טעם לעשות שום דבר אחר לפני שיש תשובה.

**איפה:**
1. להיכנס ל-**console.cloud.google.com**
2. בתפריט הצד — **Billing** (חיוב)
3. לבחור **Credits** (קרדיטים)

**מה מחפשים:** שורה של קרדיט קידום מכירות עם **יתרה** ו**תאריך תפוגה**.

| מה רואים | המשמעות | המסלול שנפתח |
|---|---|---|
| יש יתרה, התאריך בעתיד | ההפקה מכוסה מהקרדיט | ✅ **מסלול B** — מותר לפי כללי הפרויקט |
| אין יתרה / פג תוקף | כל קריאה = כסף אמיתי | ⚠️ **מסלול A או A+** |
| אין תפריט Billing בכלל | אין חשבון חיוב | ⚠️ **מסלול A** |

**מה לעשות עם התשובה:** לכתוב לסוכן שורה אחת — "יש קרדיט, מסלול B" או
"אין קרדיט, מסלול A". הוא יעדכן את `CLAUDE.md` בהתאם.

> ההנחיה המקורית שלך מתירה `free credits` בדיוק כמו `free tiers`.
> לכן קרדיט פעיל = $0 לפי הכללים שלך, ולא חריגה מהם.

### ☐ 2.1 אסימון Cloudflare — לתמונות חינם *(היה חובה למסלול A)*

**למה:** ~500 תמונות ביום, בחינם, ובאיכות טובה מהנתיב הקיים.

**איפה:**

3. לבחור **Use REST API**
4. ללחוץ **Create a Workers AI API Token**
5. ללחוץ **Create API Token**, ואז **Copy API Token**
6. באותו מסך — להעתיק גם את **Account ID**

| שם המשתנה | הערך |
|---|---|

| `CF_ACCOUNT_ID` | ה-Account ID משלב 6 |

### ☐ 2.2 Google Flow Music — שיר אמיתי בחינם *(למסלול A+)*

**למה:** אותו מנוע Lyria 3 Pro שנותן את השיר האמיתי, אבל בחינם — במקום
ביט מסונתז וראפ מדובר. **בלי כרטיס אשראי.**

**איפה:**
1. **labs.google/fx** → לבחור **Flow Music**
2. להתחבר עם חשבון Google
3. להדביק את מילות השיר ואת תיאור הסגנון שהסוכן יכין
4. **Download** → לשמור את הקובץ

**מה לעשות עם הקובץ:** להעלות לריפו כ-`assets/audio/song.mp3` (או לשלוח לסשן).

**המחיר:** ידני, ובלי חותמות הזמן האוטומטיות — הסוכן ישלים אותן ב-`stable-ts`.
