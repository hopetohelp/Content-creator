## 2. שיר ושירה — Lyria 3 *(מסלולים B/C)*

**זו ההמלצה המרכזית של המחקר.** מחליף גם את `beat.py` וגם את `tts.py`,
ומבטל את כל שלב הסנכרון.

```bash
cat > /tmp/lyria.json <<'JSON'
{"contents":[{"parts":[{"text":"<תיאור סגנון + מילות השיר המלאות>"}]}]}
JSON

curl -s -X POST \
 "https://generativelanguage.googleapis.com/v1beta/models/lyria-3-clip-preview:generateContent?key=$GEMINI_API_KEY" \
 -H "Content-Type: application/json" -d @/tmp/lyria.json -o /tmp/lyria.json.out

# האודיו
jq -r '.candidates[0].content.parts[]|select(.inlineData)|.inlineData.data' \
  /tmp/lyria.json.out | base64 -d > assets/audio/song.mp3

# חותמות הזמן והמילים — לשמור! זה הבסיס לכתוביות
jq -r '.candidates[0].content.parts[]|select(.text)|.text' \
  /tmp/lyria.json.out > assets/audio/song_lyrics.txt
```

**מה חוזר ב-`song_lyrics.txt`:**
```
[0.0:]  Screen glows dim, a familiar dread
[3.2:]  Just a little warning that my power's in the red
[6.4:]  Ten on the battery? Bet.
[9.6:]  Ten on the tokens? Dead.
```
המספר = שנייה שבה השורה מתחילה. **כל שורה כזאת = כרטיס כתובית עברית אחד**
עם אותם זמנים בדיוק. אין מיפוי מילה-למילה (סדר המילים בעברית שונה).

**בפרומפט חובה לציין:** סגנון, ‎150 BPM half-time, **male vocals only**, ואת מילות השיר במלואן.

**מדוד תמיד אחרי:**
```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 assets/audio/song.mp3
ffmpeg -hide_banner -i assets/audio/song.mp3 -af volumedetect -f null /dev/null 2>&1 | grep mean_volume
```
פחות מ-20 שניות, או ‎mean_volume מתחת ל-‎-40dB ⇒ כישלון. לייצר מחדש.

⚠️ `lyria-3-clip-preview` נמדד ב-**30.77 שניות**. ל-90 שניות: לנסות
`lyria-3-pro-preview` (**לא נבדק**, $0.08), או לתפור 3 קטעים. **לתפור רק אם התפר על תיבה.**

## 3. קול — Gemini TTS *(חינם בכל המסלולים)*

מחליף את Kokoro. איכות טובה יותר, בלי 330MB הורדה בכל סשן.

```bash
curl -s -X POST \
 "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-tts-preview:generateContent?key=$GEMINI_API_KEY" \
 -H "Content-Type: application/json" -d '{
  "contents":[{"parts":[{"text":"Say with a dry deadpan rapper delivery: <שורה>"}]}],
  "generationConfig":{"responseModalities":["AUDIO"],
    "speechConfig":{"voiceConfig":{"prebuiltVoiceConfig":{"voiceName":"Charon"}}}}}' \
 -o /tmp/tts.json

# מחזיר PCM גולמי — חייבים להמיר
jq -r '.candidates[0].content.parts[0].inlineData.data' /tmp/tts.json | base64 -d > /tmp/t.pcm
ffmpeg -v error -f s16le -ar 24000 -ac 1 -i /tmp/t.pcm assets/audio/line_01.wav -y
```

⚠️ **הפרמטרים `-f s16le -ar 24000 -ac 1` הם חובה** — המודל מחזיר PCM בלי כותרת.
בלעדיהם מקבלים רעש.

**מתי בכל זאת Kokoro:** אם Gemini נופל או אין רשת. `tools/tts.py` נשאר בריפו כגיבוי.

## 4. תמונות

### מסלול B/C — Nano Banana

```bash
curl -s -X POST \
 "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-image:generateContent?key=$GEMINI_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{"contents":[{"parts":[{"text":"<שוט>. male character only, no women, no female characters, no background people. Cinematic, 16:9."}]}]}' \
 -o /tmp/img.json

jq -r '.candidates[0].content.parts[]|select(.inlineData)|.inlineData.data' /tmp/img.json \
```

⚠️ **חוזר ב-1376×768, לא ב-1920×1080.** להתאים תמיד:
```bash
ffmpeg -i assets/stills/shot_01.jpg \

  assets/stills/shot_01_hd.jpg -y
```

### מסלול A — Cloudflare Workers AI *(חינם, ~500 תמונות ביום)*

→ **Create Token** → הרשאת **Workers AI**. את הערך שמתקבל לשמור כמשתנה סביבה
`CF_API_TOKEN`, ואת מזהה החשבון כ-`CF_ACCOUNT_ID`.

```bash
curl -s -X POST \
 "https://api.cloudflare.com/client/v4/accounts/$CF_ACCOUNT_ID/ai/run/@cf/black-forest-labs/flux-1-schnell" \

 -d '{"prompt":"<שוט>, male character only, no women","steps":4}' \
 | jq -r '.result.image' | base64 -d > assets/stills/shot_01.jpg
```

*(לא נבדק — לא היה אסימון בסביבה. **לאמת את התמונה הראשונה בעין** לפני שממשיכים.)*

## 5. שוטים, תנועה והרכבה — בלי שינוי

הנתיב הקיים נשאר. **המחקר לא מצא שום דבר טוב יותר בסביבה הזאת.**

- תנועה בפילטרים של ffmpeg: `zoompan`, `crop` דינמי, glitch, פיצול RGB, `xfade`
- 🔴 **כל שוט מקודד ל-MP4 נפרד, ואז `concat`. לעולם לא רינדור אחד ארוך**
- `-preset fast -crf 20 -pix_fmt yuv420p`, 1920×1080, 30fps
- החיתוכים נופלים על הדופק. ב-150 BPM תיבה = **1.6 שניות**

**Remotion:** מפתה, אבל מרנדר דרך Chromium **פר פריים** — 2700 פריימים ל-90 שניות.
לשם השוואה, נמדד כאן: צילום שוט אחד ב-Chromium = **9.1 שניות**, ומעבר ffmpeg מלא על
90 שניות = **4.2 דקות**. 🟡 **רק לשוט טיפוגרפיה בודד (שורת המם), לא לקו הראשי.**

## 7. MCP וסקילים — לא להוסיף

**MCP:** להשאיר את חמשת השרתים שב-`.mcp.json`. **Playwright הוא היחיד שבאמת נחוץ.**
כל שרת נוסף = עוד `npx -y` שצריך להצליח בכל עליית סשן בסביבה שנמחקת בכל פעם.
שרתי ffmpeg-MCP נבדקו ונפסלו: **קריאה ישירה ל-ffmpeg גמישה יותר וניתנת לדיבוג.**

**סקילים:** אחד בלבד שווה בדיקה — **`music-to-video`** (heygen-com/hyperframes,

סקילים של ElevenLabs / Suno / MiniMax נוגדים את אילוץ ה-$0.

## 8. אימות — הכלל שגובר על הכל

> **פיצ'ר או שוט אינו גמור בלי תוצר אמיתי שמוכיח שהוא עובד.**
> קוד יציאה 0 מ-ffmpeg אינו הוכחה. פריים שחור, אודיו שקט וקובץ באורך 0
> כולם מחזירים 0.

לכל תוצר:

| סוג | הבדיקה |
|---|---|
| אודיו | `ffprobe` למשך + `volumedetect`. מתחת ל-‎-40dB = שקט = כישלון |
| **מגדר הקול** | **חובה על כל אודיו עם קול** — הנוהל למטה |
| תמונה | **לפתוח ולראות בעין** — במיוחד "אין נשים" |
| וידאו | `ffprobe`: יש stream וידאו **וגם** אודיו, `pix_fmt=yuv420p` |
| כתובית עברית | `rtl_probe.py` — **לא בעין.** בדיקה חזותית של טקסט דו-כיווני אינה אמינה |

### בדיקת מגדר הקול — חובה

`tools/tts.py` חוסם מזהי-קול נשיים, **אבל הוא מכסה רק את Kokoro.** קול שמגיע
מ-Lyria או מ-Gemini TTS לא עובר דרכו כלל. לכן כל קובץ אודיו עם קול **נבדק
במדידה על האודיו עצמו**, לפני שהוא נכנס לריפו:

```bash
b64=$(base64 -w0 <קובץ האודיו>)
printf '{"contents":[{"parts":[{"inline_data":{"mime_type":"audio/mpeg","data":"%s"}},
  {"text":"Listen. Is the singing voice male or female? Answer ONLY JSON:
  {\"singer_gender\":\"male\"|\"female\"|\"unclear\",\"confidence\":\"high\"|\"medium\"|\"low\"}"}]}]}' \
  "$b64" > /tmp/voice.json

curl -s -X POST \
 "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-lite:generateContent?key=$GEMINI_API_KEY" \
 -H "Content-Type: application/json" -d @/tmp/voice.json \
 | jq -r '.candidates[0].content.parts[0].text'
```

`gemini-3.1-flash-lite` חינם רשמית, ולכן הבדיקה תקפה גם במסלול A.
**כל תשובה שאינה `male` בביטחון גבוה ⇒ הקובץ נפסל ומיוצר מחדש.**

🔑 **ולהריץ תמיד גם קובץ בקרה שידוע שהוא גברי** (למשל
`tests/research/gemini_tts_line.wav`). אם השופט טועה בבקרה — **הבדיקה פגומה,
לא התוצר**, ואסור להאמין לפסק הדין שלה.

### למה דווקא כך, ולא לפי גובה הצליל

ניסיתי קודם למדוד את תדר היסוד (F0) של השירה. התוצאה: חציון 296Hz ו-74%
מהמסגרות מעל 200Hz — כלומר "קול אישה". **הבדיקה הזאת הייתה שגויה.** היא רצה
על המיקס המלא, ומדדה סינתיסייזרים, האטס והרמוניות — לא את הקול. שלושה מודלים
עצמאיים ששמעו את האודיו עצמו קבעו **קול גברי בביטחון גבוה**, וקובץ הבקרה עבר.

> **לאמת את הבדיקה לפני שמאמינים לפסק הדין שלה.** בסשן ההקמה שלוש בדיקות מדידה
> החזירו תוצאה שגויה כי הבדיקות היו פגומות, לא התוצר. **זו הפעם הרביעית.**
