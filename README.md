# Content-creator

סביבת הפקה לקליפ מוזיקלי AI, בכלים מקומיים וחינמיים. **העבודה בסשן ענן.**

## סשן חדש מתחיל כאן

```bash
bash tools/bootstrap.sh          # 1. הסביבה חד-פעמית ונמחקת. זה משחזר אותה.
cat PROGRESS.md                  # 2. מה כבר נעשה ומה תפוס
bash tools/claim.sh <מספר שלב>   # 3. לתפוס שלב לפני העבודה הראשונה
```

> ואחרי כל שוט, קטע או קובץ אודיו: `bash tools/checkpoint.sh "מה נשמר"`.
> מה שלא נדחף לריפו — נעלם עם הקונטיינר.
